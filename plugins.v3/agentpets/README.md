# 助手形象

为 Agent 助手提供可替换的形象，包括全屏活动的小映、小天照、奶龙、克里斯蒂娜助手、克里斯蒂娜（z256专属），以及兼容 Codex Pet 格式的导入形象和普通精灵图素材包定制的入口外观。

> 需要支持助手形象扩展的 MoviePilot 主程序，前端和后端都需要升级到包含该功能的版本。更早的主程序可以安装本插件，但不会出现这些形象，配置页顶部会提示升级。
>
> 适用于已启用 MoviePilot Agent 助手、想把右下角的机器人换成别的形象的场景。

## 功能概览

启用插件后，个人设置的「助手形象」里会出现多个形象，每个用户自行选择，管理员也可以在系统设置中设为默认。每个形象都带一张方形头像，选中后 Agent 面板里的头像和名称也会跟着换。

插件只替换助手的外观和互动，不能代替用户发送消息，也不会接管助手面板、会话和模型。

### 全屏角色

小映是原创 Q 版看板娘，在整个页面上活动。

- 点击或用键盘 Enter / Space 打开助手面板
- 按住拖动会把她拎起来；自主活动时松手按活动范围落位，固定位置时停在松手处
- 空闲时偶尔散步、眨眼，走路是左右脚交替的四帧循环，步伐按走过的距离推进，调快速度也不会滑步
- 跟随助手状态换动作，思考、调用工具、等待确认、完成、出错、气泡和流式预览各有对应表情，长时间没有互动会打盹
- 自主活动时会避让按钮、链接和菜单项；手动放到卡片顶沿附近时吸附站稳，优先保留该站立面，离开或支撑失效后恢复避让。底边或自由停放时，被放到控件上约 1.5 秒后走开
- 手机等窄屏上在设置的大小基础上再缩小两成
- 记住每个用户的落脚点（活动范围和位置），在拖拽放下、改变活动范围和离开页面时保存，下次打开页面时按当前活动范围重新落位
- 系统开启「减少动态效果」时不播散步和下落，需要换位置时直接瞬移，页面切到后台时停止所有动画
- 帧图加载失败（例如服务重启中）时停在上一帧，不会出现破图框

活动方式分为「自主活动」（默认）与「固定位置」。固定位置关闭散步、下落、跟随平台、探头和自动避让；仍可拖拽、眨眼并响应会话状态。位置按视口比例保存，软键盘或窗口暂时缩小时只限位显示，恢复后回到原落点。固定模式隐藏速度与活动范围设置，保留原值供切回自主活动时使用。

自主活动的活动范围有三种。

- **站在页面元素上**（默认）。落到正下方最近的卡片、面板或对话框上边，在上面走动，走到边缘会转身，偶尔跳下去。元素滚动、移动时她跟着走，元素缩小、关闭或滚出屏幕时她掉下去，没有可站的元素时落到屏幕底边
- **只在底边**。始终站在屏幕底边，偶尔走到一侧只探出上半身
- **自由活动**。没有重力，放在哪里停在哪里，空闲时在屏幕内慢慢游走

可站元素要求宽度至少 120 像素、上边缘在屏幕内、上方留得下她的身高，并且没有被遮罩或其他元素盖住。Agent 面板自身和不可见的元素不算。

自主活动且允许动画时，角色空闲约 6–14 秒选择一次行为；站在底边时有 25% 概率走到左／右下角偷看。选中偷看后，底边与对应侧边各占一半；固定位置、忙碌、打盹时不随机触发，自由活动仍以游走为主。此规则供小映、内置逐帧 Pet 与 Codex Pet 共用。

三只形象随插件离线分发，无需导入，也不写入用户素材库；已有同名或类似形象的 ID、图片、校准和设置均保持不变。每只可独立调整大小、速度与三边偷看角度。原生动画可在详情页试播，拖动、下落、会话反应与底边偷看复用现有舞台。

### 兼容 Codex Pet 格式的全屏角色

通过导入器生成的 Codex Pet 与小映各自保存角色大小和移动速度，仅共用活动方式与活动范围设置，可拖拽、站在页面元素上、散步和探头。行走分别使用原始向左、向右的动画行；助手思考、说话与完成状态使用素材包动作映射。

已有导入包按 Codex 网格及 idle、wave、happy-jump 的帧布局识别，保留形象 ID、原图与自定义动作。旧精简包缺少的行走等动作只在显示时补齐，无需删除或重新导入；普通素材包继续作为入口外观。

### 动画预览、映射与重命名

详情页保留完整原生动画预览：Codex Pet 的九组原生动画直接试播，不受映射覆盖影响；v2 另有 16 向视线预览。已有自定义动画保留，相同帧序列的适配别名不会重复算作新动画。小映提供完整姿态预览，入口形象提供 MP 动作与入口状态预览，全屏形象可模拟会话事件。

导入的 Codex Pet 可在详情页「动作映射」中为日常、会话、移动交互分别选择动画，例如思考、执行工具、完成、拖起和左右行走。映射以 Pet ID 独立保存，原始 `frames`、`actions` 和图片不变；留空或清除单项使用原有映射，也可恢复全部默认。缺少专用动画时提示使用待机。草稿只影响预览；「保存调整」保存活动参数、已修改 Pet 的映射与显示校准，「撤销」恢复已保存值。大小、速度与偷看角度按 Pet ID 独立保存；活动方式与范围仍由全屏角色共用。

管理页的已导入 Codex Pet 卡片提供重命名，名称去除首尾空格后须为 1～40 个字符。仅显示名称变化，Pet ID、当前选择、动画、映射与用户位置保持不变。保存后更新管理卡片；详情页和宿主形象目录重新读取时显示新名称。内置形象不可重命名。

名称和映射保存均检查调用方读取的旧值；其他页面已修改时拒绝覆盖。映射草稿遇到外部更新时显示冲突提示，点击「撤销」载入最新值后重新调整，切换 Pet 或刷新不会绕过旧值检查。写入仅允许管理员。保存映射后通知当前页面对应实例与 Pet 重新读取，其他页面重新加载后取得新值。

| API | 用途 |
| --- | --- |
| `POST /api/v1/plugin/AgentPets/packs/rename` | `id`、`name`、`expected_name`；重命名并回读 |
| `POST /api/v1/plugin/AgentPets/packs/mappings` | `id`、`mappings`、`expected_mappings`；保存覆盖或用空对象恢复默认 |

### 素材显示校准

Codex Pet 选择「校准」与「完整形象」，拖动标有「画面左眼」「画面右眼」的光圈到瞳孔中心，头顶标记放到实际头顶而非透明留白。虚线圈为待标定候选位置，打开界面不会写入坐标；「放大头部」便于细调，也支持鼠标、触摸与方向键（Shift 加快），Esc 取消本次拖动。贴边试览时停止编辑标记，保留底边及左右下角侧边检查。

三个点使用原图单格的 `left_eye_x/y`、`right_eye_x/y`、`head_top_x/y` 归一化坐标，每组横纵坐标必须同时存在，左眼在右眼左侧、头顶在双眼上方。拖动按真实显示框反算裁切、偏移与缩放，只有点击「保存调整」才生效。双眼未标齐时继续使用旧 `eye_x/y` 中点；「清除三点」仅清除新标记，恢复旧中点行为。

已导入素材在详情预览中可调整统一显示区域、脚底基线和水平／垂直偏移，并切换原始显示对照、显示参考框与底线。全部动画共用同一个框，不逐帧缩放；框外内容在显示时裁切，原始图片、帧序列与动作均保留。舞台边界和拖拽尺寸随有效显示区域更新。

「识别建议」读取已上传图片的透明边界，合并全部已定义帧及 Codex 显示补齐帧，按 idle 帧给出脚底基线；只生成草稿。远程 URL 素材可手动校准，自动识别需先上传图片。「恢复默认」也只改草稿，点击底部「保存调整」才持久化。其他页面已修改校准时拒绝覆盖，撤销后重新读取再调整。

### 完整素材包导出与导入

素材管理的已导入素材卡片提供「导出素材包」，生成 `<id>.agentpets.zip`，包含名称、说明、原始帧与动作、随机动作、自定义映射、显示校准、原始精灵图及现有预览图／头像。远程图片必须完整读取成功才会生成文件；跨域或网络失败会提示导出失败。

在「导入 Pet」区域切换到「AgentPets 素材包」，选择导出的 ZIP，先核对名称、图片与网格。相同 ID 默认「导入副本」，生成独立 ID 并保留原素材；明确选择「更新同 ID 素材」后展示覆盖范围与前后数量，核对后点击「确认覆盖此素材」。覆盖保留 ID、当前形象选择与个人位置，不允许普通入口形象与全屏角色相互覆盖。读取后素材被其他页面修改时，旧修订号会阻止覆盖。

覆盖前把上一份记录保存在插件数据键 `pack_backup_<id>`，并保留已上传的原图文件（远程来源仅保留原 URL）；恢复副本保存失败或无法回读时不覆盖。每个 ID 保留最近一次覆盖前的记录，旧图不自动清理；这份恢复记录用于故障排查，目前没有一键恢复界面，日常备份请保留导出的 ZIP。写入后状态不明会保留可恢复文件并提示核对，不把异常报告为成功。

ZIP 使用 `agentpets.json`（格式 `agentpets`、版本 `1`）和 `sheet.img`，可含 `preview.img`、`avatar.img`；图片保留原始字节并按内容识别格式。ZIP 上限 8MB，清单 64KB，精灵图 4MB，预览图和头像各 128 KiB，图片边长不超过 4096 像素。此格式使用「AgentPets 素材包」选项；Codex 的 `pet.json` ZIP 使用同一导入器中的「Codex Pet」选项。素材操作立即保存，不依赖详情页的「保存调整」。

### 入口外观

普通素材包只替换右下角助手入口的画面。拖拽、贴边、点击打开面板和气泡仍由主程序负责，行为和内置机器人一致。

- 内置戴红色贝雷帽的橘猫「放映猫」
- 每个素材包是一张精灵图加一份动作映射 JSON，按主程序传来的动作名和状态播放帧序列，没有对应映射时依次回落到状态、思考中和 idle
- 主程序暂停动画时只显示当前动作的第一帧
- 用户素材包在读取完成前不显示画面，读取失败时显示放映猫
- 管理员可在配置页添加素材包，上传的精灵图保存在插件数据目录，不写进插件代码目录
- 配置页可导入 Codex Pet ZIP 包或直接上传原生精灵图；v2 的 16 向帧可用于 scan 动作

## 在线形象市场扩展

插件默认注册 [Codex Pets](https://codex-pets.net/)（`codex-pets`）、[OpenPets](https://openpets.dev/)（`openpets`）和 [Petdex](https://petdex.dev/)（`petdex`）。配置页「在线市场」提供市场切换、关键词搜索、分页、预览和导入确认，并保留相应 API。插件初始化和读取市场列表均不访问网络，只有搜索或导入时请求对应站点。

### 页面浏览与导入

进入配置页「在线市场」后选择形象市场，可按名称或关键词搜索，搜索和切换市场均回到第一页。结果卡片展示图片、作者与说明；点击预览或「导入」可查看来源和许可，并选择「新增素材」或「导入副本」后确认。未知总量时仍可按上游返回的下一页状态翻页，预览图加载失败时显示占位图。

浏览接口供登录用户使用，导入仍由后端验证管理员权限；权限不足、ID 冲突或市场不可用时保留确认内容并展示失败原因，不报告成功。导入成功会即时保存，刷新已打开的本地素材列表与运行概览，无需再点击「保存配置」。同一页面已导入的远程形象再次选择时默认采用副本模式，跨页面或历史素材的 ID 冲突仍以存储校验为准。

切换插件实例会清空对应市场状态并忽略旧请求结果；切换市场或连续搜索时，较早返回的结果不会覆盖最新内容。桌面使用侧栏导航，手机使用两列分组入口，确认弹窗中的图片与说明独立布局。

### Codex Pets

[markets/providers/codexpets.py](markets/providers/codexpets.py) 对接站点的公开 `/api/pets` 目录及 `/api/pets/<id>/download` 下载端点，不需要站点账号或 API 密钥。支持关键词搜索、分页，以及 Codex Pet v1（8×9）和 v2（8×11）ZIP 素材转换；动作与已有前端导入器一致，v2 保留 16 向视线动画。

搜索示例：`GET /api/v1/plugin/AgentPets/markets/items?market_id=codex-pets&keyword=cat&page=1&page_size=20`。从响应 `items` 取得远程 `id` 后，调用导入 API，传入 `market_id=codex-pets`、`item_id=<远程 id>` 和 `mode=new` 或 `copy`。导入仍只允许管理员，既有素材不会被市场下载覆盖。

本地素材 ID 为 `codex-` 加远程 ID 的 SHA-256 前 24 位，满足本地长度限制，并保持同一市场形象重复导入时 ID 稳定；显式导入副本时由存储层生成独立 ID。名称与说明截取到本地素材的 40 / 120 字符上限，其他字段继续经过现有素材校验。

作者取自上游 `ownerName` 或 `ownerHandle`，预览使用站点的 `posterUrl` 或 `previewUrl`，来源链接指向原形象页。仅当上游返回具体素材的 `license` 字符串时展示许可；否则为空，不以网站或程序源码的开源许可代替素材授权。

网络请求通过宿主 SDK，启用 TLS 校验、严格限定站点域名并拒绝解析到非公网地址；不跟随重定向，也不使用目录返回的任意下载 URL。目录响应最多 1 MiB、ZIP 最多 8 MiB，按流累计限额，单次请求超时 20 秒，流读取另设 30 秒截止检查。ZIP 最多 256 个条目、声明解压总量最多 16 MiB，只读取唯一 `pet.json`（64 KiB）及其精灵图（4 MiB），拒绝越界路径、重复路径、加密文件和符号链接，不向磁盘解压。

站点不可用、形象下架、限流或素材格式不支持时返回失败信息，现有本地形象仍可继续使用。

### Petdex

[markets/providers/petdex.py](markets/providers/petdex.py) 对接匿名公开的 `/api/pets/search`。统一 `page` 映射为 `(page-1)*page_size` 的 `cursor` 偏移量，关键词使用 `q`、每页数量使用 `limit`，显式采用字母排序并请求总量。下一页依据 `nextCursor` 判断；总量未提供时保持 `null`，搜索失败时不改用本地目录搜索，避免更改匹配和分页语义。

搜索示例：`GET /api/v1/plugin/AgentPets/markets/items?market_id=petdex&keyword=boba&page=1&page_size=20`。导入 API 的 JSON 使用 `{"market_id":"petdex","item_id":"boba","mode":"new"}`，`item_id` 为搜索返回的 slug；也可显式选择 `mode=copy`。

导入通过公开 `/api/manifest/v2` 精确查找 slug，不依赖之前搜索的内存结果。紧凑目录的版本、字段顺序、记录类型、重复 slug、总量和所有资源地址均经过检查；目录版本 `v=2` 与图片版本不是同一个概念。成功解析的目录在单个插件实例内缓存 300 秒，最多 20000 条、响应最多 8 MiB；刷新失败不把过期记录用于新的导入，也不缓存下载图片或 ZIP。

首选目录声明的 ZIP；只有未声明 ZIP 时，才分别读取目录指定的清单与图片。坏 ZIP 或格式校验失败直接报告错误，不切换资源绕过检查。不会调用带安装计数副作用的 `/api/install-pet/<slug>`，也不读取或执行安装脚本。

支持 Codex v1/v2 标准图及保持原始宽高比、所有格子边界为整数的等比缩放图，不对图片重采样。实际图片须与素材清单中的显式版本一致；目录摘要中的过时版本标签不用于最终判版。Codex Pets 和前端手动 Codex 导入原有的标准尺寸策略保持不变。

资源仅允许 HTTPS 的 `assets.petdex.dev`。只有 manifest 允许一次 307/308 跳转到该 CDN 的 `/manifests/` 路径，每一跳重新检查精确域名、凭据、端口、路径和非公网解析；图片、ZIP 不自动跳转。下载、图片、清单和 ZIP 解包限制与 Codex 共用，搜索响应仍限 1 MiB。

本地素材 ID 使用 `petdex-` 加 slug 的 SHA-256 前 24 位，与已有 `codex-` 素材隔离。作者来自 `submittedBy.name`，来源链接指向原形象页面；只有上游明确返回素材许可字符串时才展示，未声明时保持未知，不推断为站点源码的 MIT 许可。

### OpenPets

[markets/providers/openpets.py](markets/providers/openpets.py) 对接公开 `/pets/catalog.v3.json`。无关键词时按原目录顺序浏览，只读取本页需要的目录分片，统一页大小可以跨越远程页边界。有关键词时读取轻量搜索索引和分片，对 ID、名称与上游 `searchText` 做宽度及大小写归一化后的多词包含匹配，再按需读取完整摘要。搜索总量为本次匹配数量，空结果与目录读取失败分别处理，不回退到旧目录或伪造空结果。

搜索示例：`GET /api/v1/plugin/AgentPets/markets/items?market_id=openpets&keyword=meat&page=1&page_size=20`。导入 API 使用 `{"market_id":"openpets","item_id":"meat-proxy","mode":"new"}`，`item_id` 为目录中的 ID，不是资源目录 slug；支持显式 `mode=copy`。

目录根索引和成功读取的页面按实例缓存 300 秒，最多 20000 项、200 个分片。索引响应最多 128 KiB，单页最多 2 MiB；刷新成功清空旧页面和搜索缓存，刷新失败不把过期记录作为成功结果继续导入。根索引、分片数量、页码、记录 ID、版本、搜索快照及页映射均经过检查；不因页面返回任意 URL 而扩大网络白名单。

目录和预览资源限定 HTTPS `openpets.dev/pets/`，ZIP 限定 HTTPS `zip.openpets.dev/pets/<slug>/<id>.zip`，不自动跳转。导入不依赖先前浏览，按搜索映射精确定位完整目录记录，再下载官方包。下载和容器解压继续使用共用限额，不向磁盘展开 ZIP。

[formats/openpets.py](formats/openpets.py) 单独校验包结构：根目录或单个顶级目录下只能有 `pet.json` 和 `spritesheet.webp`，二者必须同目录。包内 ID 和版本须与选择的目录记录一致，清单必须引用真实 WebP 图集；标准 v1/v2 动作映射复用 Codex 转换。当前不支持 OpenPets 的 SVG 图集，选择此类包会明确返回不支持提示，不会静默转换或保存坏素材。

本地 ID 为 `openpets-` 加远程 ID 的 SHA-256 前 23 位，保持稳定且符合 32 字符上限，与另外两家市场隔离。来源链接使用官方详情 slug；作者和许可只读取明确的字符串字段，未提供时保持未知，不把站点源码许可当作素材授权。

### 适配器契约

[markets/contracts.py](markets/contracts.py) 定义同步抽象类 `MarketAdapter`，每个市场实现以下成员。

| 成员 | 返回类型 | 职责 |
| --- | --- | --- |
| `info` 属性 | `MarketInfo` | 稳定的市场 `id`、名称、说明与可选主页 |
| `search(query)` | `MarketPage` | 按 `MarketQuery` 分页搜索；空关键词表示浏览 |
| `fetch(item_id)` | `MarketPack` | 按市场内形象标识下载并转换为完整 AgentPets 素材 |

统一数据约定：

- `MarketInfo.id` 使用 1～32 个小写字母、数字、`-` 或 `_`，在插件内唯一且应长期稳定
- `MarketQuery` 包含 `keyword`、`page`、`page_size`；关键词最多 200 字符，页码从 1 开始且不超过 10000，每页默认 20 条、最多 50 条
- `MarketPage` 包含 `items`、`total`、`has_more`；当前页条数不得超过请求的 `page_size`。上游不提供总量时 `total` 为 `null`，由适配器确定 `has_more`
- `MarketItem` 包含 `id`、`name`、`description`、`author`、`license`、`preview`、`source_url`；作者、许可和链接可缺省，许可为空表示未知，不推断授权。预览和来源链接仅接受 HTTP(S)
- 形象 `id` 只需在对应市场内唯一，可包含上游命名空间，与本地素材包 ID 相互独立；API 使用 `market_id` 与 `item_id` 定位远程形象
- `MarketPack.pack` 是下文素材包格式对应的字典，`MarketPack.image` 是已下载的原始图片字节，最大 4MB；第三方 ZIP、清单和动画布局由适配器转换，不向本地存储传入任意文件路径或下载指令
- 可预期的上游不可用、形象不存在或格式不支持应抛出 `MarketError`；消息可直接展示，不得包含凭据、内部地址或上游响应正文

### 注册与导入

新增市场时，在 `markets/providers/` 新建模块，继承 `MarketAdapter`，声明类属性 `market_id = "example"`，并添加从 [markets/registry.py](markets/registry.py) 导入的 `@register_market` 装饰器。实现 `info`、`search`、`fetch`，`info.id` 使用 `self.market_id`，构造函数不得访问远程服务。无需修改注册工厂或供应商包的导出列表。

`MarketAdapter` 仅定义接口与身份字段，继承本身不触发登记；中间类和测试替身不添加装饰器即可保持未登记。`@register_market` 显式校验并保存供应商类，拒绝非法或重复的市场 ID、非适配器类型，以及仍未实现抽象接口的供应商，返回原类而不创建实例。

工厂按名称顺序发现并导入本地 `markets/providers/` 中非下划线开头的模块，导入时执行装饰器；随后按市场 ID 排序，为每个插件实例分别创建适配器。全局只保存类型，不共享实例缓存、锁或网络连接。

每个插件实例仍有独立市场索引，装配时检查类声明与 `info.id` 是否一致。自动发现仅限插件自身的本地供应商包，API 不根据请求输入导入模块。

### 包容器与素材格式

下载资源的压缩形式与素材内容是两个独立选择。市场适配器根据实际协议选择容器和内容解析器，最终返回统一的 `MarketPack`；新市场不必使用 Codex 格式。

- `PackageReader` 约定只读文件列表、限额读取、包内相对路径解析和关闭操作，不约定清单文件名、目录层级、图片类型或动画格式
- `ZipPackageReader` 实现 ZIP 的路径与重复项检查、压缩及解压额度、加密和符号链接拒绝、损坏数据处理，不向磁盘解压；其他容器可独立实现 `PackageReader`
- `read_codex_package()` 只解释 Codex 的唯一 `pet.json` 与 `spritesheetPath`，可读取 ZIP 容器或任何其他满足接口的容器
- `read_openpets_package()` 在共享读取之上校验 OpenPets 自己的两文件布局和目录身份，拒绝不支持的 SVG 图集
- `build_codex_pack()` 从已取得的清单和图片生成内部素材，Petdex 的独立 JSON 与图片下载直接进入此步骤

现有市场按各自协议组合安全 ZIP 容器和内容解析器。以后新增其他清单命名、文件布局或动画格式时，在 `formats/` 添加对应解析实现；不同市场可以复用同一种解析器，容器安全规则无需重复实现。目前只实现已需要的 ZIP 容器，不自动猜测未知包格式或下载其他资源绕过校验。

适配器只负责发现、下载和转换，不修改插件配置、素材记录或插件数据目录。网络实现应使用宿主公开网络与 URL 安全接口，限制可信上游域名、每次重定向、请求超时、响应字节数与解压大小，并根据该市场规则校验形象标识；不能把用户提供的标识直接当作任意 URL 下载。`MarketPack` 的图片大小检查不替代下载期间的流量上限。

导入 API 将下载结果交给现有完整包导入链路，继续检查帧引用、图片类型、网格、尺寸、内置 ID 和最多 20 个素材包等限制。默认 `mode=new`，同 ID 已存在时拒绝写入；明确使用 `mode=copy` 时生成独立本地 ID。市场导入不支持 `replace`，需要更新已有素材时仍使用原有的完整包导入及修订号核对流程。

导入成功返回现有素材摘要，之后可由 `packs`、`pack` 和宿主形象目录读取。市场搜索本身不保存素材；只有导入写接口需要管理员权限。

### 市场 API

所有路径均以 `/api/v1/plugin/AgentPets` 为前缀，沿用 `success`、`message`、`data` 响应结构。

| API | 参数与结果 |
| --- | --- |
| `GET /markets` | 登录用户可用；`data` 为已注册的 `MarketInfo` 数组，未接入市场时为 `[]` |
| `GET /markets/items` | 登录用户可用；查询参数为必填 `market_id`、可选 `keyword`、`page=1`、`page_size=20`；`data` 包含 `market_id`、`page`、`page_size`、`items`、`total`、`has_more` |
| `POST /markets/import` | 仅管理员；JSON 为 `market_id`、`item_id`、可选 `mode`（`new` 或 `copy`）；成功时 `data` 为已导入的本地素材摘要 |

未知市场或市场访问失败返回 `success=false`；请求字段非法或分页参数越界返回 HTTP 422，无管理员权限的导入返回 HTTP 403。请求不接受下载 URL 或本地文件路径字段。

## 一个插件注册多个形象

主程序通过插件的 `get_agent_pets()` 收集形象，返回列表里的每一项都是一个可选形象。`key` 在插件内唯一，用户的选择记作 `<插件 ID>:<key>`。本插件返回下面这些形象。

| key | mode | component | 说明 |
| --- | --- | --- | --- |
| `ying` | `stage` | `AgentPet` | 小映，插件拥有整个视口图层 |
| `projector-cat` | `renderer` | `AgentPetSprite` | 内置素材包 |
| 三只 `builtin-*` ID | `stage` | `AgentPetCodex` | 内置逐帧包复用舞台，不伪装为 Codex 格式 |
| Codex Pet 素材包 ID | `stage` | `AgentPetCodex` | 复用小映舞台与设置 |
| 普通素材包 ID | `renderer` | `AgentPetSprite` | 用户添加的每个普通素材包各一项 |

同一个联邦组件可以服务多个形象。Codex Pet 声明 `AgentPetCodex`，普通素材包声明 `AgentPetSprite`，组件从宿主传入的 `pet.key` 得知要画哪个素材包。形象列表随插件数据变化，添加或删除素材包后主程序重新读取声明即可看到。`preview` 和 `avatar` 支持相对联邦产物目录（`remoteEntry.js` 所在目录）的路径，或 `http(s)`、`data:` URL。内置形象使用缓存的轻量 `data:` 图片，供宿主选择卡片和消息头像直接显示；动画仍从联邦产物加载。

## 配置说明

| 配置项 | 标识 | 类型 | 默认值 | 说明 | 备注 |

| 启用插件 | `enabled` | bool | `false` | 启用后形象出现在助手形象列表中 |  |
| 角色大小 | `scale` | number | `1` | 全屏角色的显示倍率，1 倍约 120 像素高 | 范围 0.6 到 1.6，窄屏再乘 0.8 |
| 活动方式 | `movement` | string | `auto` | `auto` 自主活动、`fixed` 固定位置 | 所有用户与全屏角色共用 |
| 移动速度 | `speed` | number | `1` | 全屏角色散步的速度倍率 | 范围 0.5 到 2 |
| 活动范围 | `roam` | string | `surfaces` | `surfaces` 站在页面元素上、`floor` 只在底边、`free` 自由活动 |  |

配置页保存开关前读取最新完整配置，保留详情页已保存的活动参数；读取失败或开关已在其他页面更改时停止提交。

配置页采用分组导航，提供运行总览、基础设置、素材管理和在线市场；标题层级、分组排版与未保存提示参考订阅助手（增强版）。详情页集中选择 Pet、调整大小/活动方式/速度/活动范围，并在独立区域实时预览。预览复用正式形象的动作与移动逻辑，拖拽、落到平台、暂停和切换动作都不会修改正在使用的形象或保存位置。

大小、速度与可选 `peek_angles` 保存为 `pet_settings[PetID]`，按稳定 ID 而非显示名称关联；没有独立值时继承旧 `scale` / `speed`，读取与升级不批量改写配置。`peek_angles` 使用 bottom / left / right，默认底边 0 度、左右侧边 35 度；旧客户端只保存大小速度时保留现有角度。活动方式与范围仍共享；同一 Pet 的设置对所有用户生效，不提供个人或手机／电脑独立偏好。「保存调整」逐项回读成功后才通知对应形象；部分保存失败时保留未完成草稿，不重复保存已成功项。跨页面旧值冲突会阻止覆盖，刷新后可撤销草稿以载入最新值。

内置显示校准单独保存在当前插件实例的 `builtin_calibrations[PetID]`，不修改图片、素材包或共享默认标定。恢复默认使用该形象原始眼位和基线；原生逐帧动作的相对基线偏移仍保留。保存需校验读取时的旧值并回读，其他页面或实例的迟到结果不能覆盖当前草稿。

预览满意后点击「保存调整」，再到 MP 的「设定 → 系统 → 智能助手配置 → 助手形象」选择 Pet。详情页不再提供「立即生效」按钮；保存活动参数不会更改系统默认形象、个人选择或刷新页面。系统默认暂不可读时仍可预览和保存活动调整。

普通入口形象可预览动作，并在 MP 设置中选择使用；位置与移动由宿主管理，不显示全屏角色的活动参数。

素材包不属于插件配置。在配置页「素材管理」中点击「添加 Pet」并校验通过后立即保存，删除也立即生效，无需再点保存。

## 素材包格式

一个素材包由一张精灵图和一份 JSON 组成。精灵图按网格等分，所有格子同尺寸，建议透明背景、角色脚底在同一基线上。

```json
{
  "id": "my-pet",
  "name": "我的形象",
  "description": "一句话介绍",
  "sheet": "https://example.com/my-pet.png",
  "grid": { "cols": 4, "rows": 2 },
  "frames": { "idle": 0, "blink": 1, "talk": 2, "think": 3, "jump": 4, "wave": 5, "sleep": 6, "sad": 7 },
  "actions": {
    "idle": { "frames": ["idle", "idle", "idle", "blink"], "frame_ms": 700, "loop": true },
    "thinking": { "frames": ["think"], "loop": true },
    "speaking": ["talk", "idle"],
    "success": { "frames": ["jump", "wave", "idle"], "frame_ms": 260 },
    "error": ["sad"],
    "wave": { "frames": ["wave", "idle", "wave"], "frame_ms": 240 },
    "sleep": ["sleep"]
  },
  "random_actions": ["wave", "sleep"]
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 否 | 素材包 ID，也是形象 key，只能用小写字母、数字、`-`、`_`，1 到 32 个字符，不填时按名称生成。`projector-cat`、`ying` 与三只 `builtin-*` ID 留给内置形象 |
| `name` | 是 | 展示名，不超过 40 个字符 |
| `description` | 否 | 一句话介绍，不超过 120 个字符 |
| `sheet` | 视添加方式 | 选择「使用 JSON 中的图片 URL」时必须是 `http(s)` 图片地址，上传精灵图时忽略 |
| `grid` | 是 | `cols`、`rows`，各 1 到 16，精灵图宽高必须能被行列数整除 |
| `frames` | 是 | 帧名到格子索引，索引从左上角 0 开始逐行编号，必须包含 `idle` |
| `actions` | 否 | 主程序动作名或状态名到帧序列，详见下文 |
| `random_actions` | 否 | 主程序空闲时随机播放的动作，只能取下文的主程序动作名，不填则从全部动作中挑 |
| `action_mappings` | 否 | MP 事件到素材动作的自定义映射，导出时保留 |
| `calibration` | 否 | `left/top/right/bottom/baseline` 为 0～1，偏移 `offset_x/offset_y` 为 -0.25～0.25；区域宽高至少 0.1，基线在区域内 |
| `preview` | 否 | 自定义预览图，`http(s)` 地址或 `data:image/...`，上传方式不填时自动裁出 idle 帧 |
| `avatar` | 否 | Agent 面板用的方形头像，`http(s)` 地址或 `data:image/...`。上传方式不填时从 idle 帧角色顶部裁出，URL 方式不填则不提供头像 |

`actions` 的每一项写成对象 `{ "frames": [...], "frame_ms": 160, "loop": false }`，也可以直接写帧名列表，此时每帧 160 毫秒、不循环。`frame_ms` 范围 40 到 5000，不循环的动作播完停在最后一帧。

`actions` 的键可以是主程序动作名，也可以是状态名。

- 主程序动作名有 `wave`、`sit`、`eye-roll`、`faint`、`disassemble`、`happy-jump`、`sleep`、`stretch`、`peek`、`scan`、`charge`、`spin-cheer`、`shy`、`confused`、`nod`、`wake`
- 状态名有 `idle`、`thinking`、`speaking`、`notify`、`success`、`warning`、`error`、`dragging`、`docked`、`sleeping`、`reaction`

播放时先找当前动作名，找不到再找当前状态，助手正在思考时再试 `thinking`，最后用 `idle`。只给 `idle` 也能用，所有动作都会显示 idle。

精灵图支持 PNG、WebP、GIF 和 JPEG，不超过 4MB、边长不超过 4096 像素。Codex Pet ZIP 不超过 8MB，包内 `pet.json` 不超过 64KB。一个实例最多保存 20 个素材包。

## 使用步骤

1. 在插件市场安装并启用「助手形象」
2. 打开个人设置中的「助手形象」，选择「小映」或「放映猫」，管理员也可以在系统设置中设为默认助手形象
3. 打开插件详情页，选择 Pet 并调整大小、活动方式、速度和活动范围，在右侧实时预览；满意后点击「保存调整」
4. 需要更多 Pet 时，在配置页「素材管理」上传 `.zip` 或原生 PNG/WebP，点击「读取 Codex Pet」后「添加 Pet」；自定义素材仍可填写 JSON 并上传图片或使用图片 URL
5. 从第三方市场获取 Pet 时，进入「在线市场」，选择市场并搜索形象，打开预览后确认「新增素材」或「导入副本」；成功后可在「素材管理」查看，随后在 MP 设置中选择使用

Codex Pet 导入支持 v1 的 1536×1872（8×9）和 v2 的 1536×2288（8×11）精灵图。ZIP 包从唯一的 `pet.json` 读取 `spritesheetPath`、ID、名称和描述；直接上传图片时按文件名生成名称和 ID。导入器把前九行动画映射到 Agent 状态与动作；v2 最后两行的 16 个视线方向保留在素材包中，并映射到 scan 动作。生成后仍需点击「添加 Pet」保存；更换输入文件后须重新读取，避免新图片沿用旧名称和动作信息。新包带有 `codex_version`（`v1` 或 `v2`）以保留布局类型，选择该形象后使用全屏舞台。

插件详情页提供独立的实时预览，可拖动形象、切换招手/思考/说话等动作或暂停动画，调整不会影响正式使用的形象；退出时释放预览实例、监听器和计时器。

## 注意事项 / 已知风险

- 删除素材包或停用插件后，选择对应形象的用户会自动回到内置机器人
- 素材包使用图片 URL 时，图片由每个用户的浏览器直接加载，地址失效或跨域受限时会显示空白，需要稳定显示时请上传精灵图
- 全屏角色站在页面元素上时只认常见的卡片、面板和对话框容器，自定义布局里的普通区块不会成为落脚点
- Codex 是 OpenAI 的商标，本插件只兼容其 Pet 素材格式，与 OpenAI 无关联，也不附带任何 Codex Pet 素材；导入素材的版权由导入者负责

- 插件日志在 `MoviePilot/config/logs/plugins/`，过滤「助手形象」
- 常见问题
  - 形象列表里没有本插件的形象 → 确认插件已启用，主程序前端和后端都已升级到支持助手形象的版本
  - 选择后仍显示机器人 → 浏览器控制台中搜索 `AgentPet`，主程序会在联邦组件加载失败或超时时回退并给出一条警告
  - 「添加 Pet」提示帧或动作错误 → 按提示检查 `frames` 索引是否超出 `cols × rows`，动作里的帧名是否都在 `frames` 中
  - 选择素材包后显示的是放映猫 → 素材包读取失败时组件会退回内置素材包，浏览器控制台里会有 `[AgentPets]` 警告
