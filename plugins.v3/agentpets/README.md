# 助手形象

为 Agent 助手提供可替换的形象，包括全屏活动的小映、兼容 Codex Pet 格式的导入形象，以及用普通精灵图素材包定制的入口外观。

> 需要支持助手形象扩展的 MoviePilot 主程序，前端和后端都需要升级到包含该功能的版本。更早的主程序可以安装本插件，但不会出现这些形象，配置页顶部会提示升级。
>
> 适用于已启用 MoviePilot Agent 助手、想把右下角的机器人换成别的形象的场景。

## 功能概览

启用插件后，个人设置的「助手形象」里会出现多个形象，每个用户自行选择，管理员也可以在系统设置中设为默认。每个形象都带一张方形头像，选中后 Agent 面板里的头像和名称也会跟着换。

插件只替换助手的外观和互动，不能代替用户发送消息，也不会接管助手面板、会话和模型。

### 全屏角色

小映是原创 Q 版看板娘，在整个页面上活动。

- 点击或用键盘 Enter / Space 打开助手面板
- 按住拖动会把她拎起来；自主活动时松手按活动范围落位，固定位置时停在松手处
- 空闲时偶尔散步、眨眼，走路是左右脚交替的四帧循环，步伐按走过的距离推进，调快速度也不会滑步
- 跟随助手状态换动作，思考、调用工具、等待确认、完成、出错、气泡和流式预览各有对应表情，长时间没有互动会打盹
- 自主活动时会避让按钮、链接和菜单项；手动放到卡片顶沿附近时吸附站稳，优先保留该站立面，离开或支撑失效后恢复避让。底边或自由停放时，被放到控件上约 1.5 秒后走开
- 手机等窄屏上在设置的大小基础上再缩小两成
- 记住每个用户的落脚点（活动范围和位置），在拖拽放下、改变活动范围和离开页面时保存，下次打开页面时按当前活动范围重新落位
- 系统开启「减少动态效果」时不播散步和下落，需要换位置时直接瞬移，页面切到后台时停止所有动画
- 帧图加载失败（例如服务重启中）时停在上一帧，不会出现破图框

活动方式分为「自主活动」（默认）与「固定位置」。固定位置关闭散步、下落、跟随平台、探头和自动避让；仍可拖拽、眨眼并响应会话状态。位置按视口比例保存，软键盘或窗口暂时缩小时只限位显示，恢复后回到原落点。固定模式隐藏速度与活动范围设置，保留原值供切回自主活动时使用。

自主活动的活动范围有三种。

- **站在页面元素上**（默认）。落到正下方最近的卡片、面板或对话框上边，在上面走动，走到边缘会转身，偶尔跳下去。元素滚动、移动时她跟着走，元素缩小、关闭或滚出屏幕时她掉下去，没有可站的元素时落到屏幕底边
- **只在底边**。始终站在屏幕底边，偶尔走到一侧只探出上半身
- **自由活动**。没有重力，放在哪里停在哪里，空闲时在屏幕内慢慢游走

可站元素要求宽度至少 120 像素、上边缘在屏幕内、上方留得下她的身高，并且没有被遮罩或其他元素盖住。Agent 面板自身和不可见的元素不算。

### 兼容 Codex Pet 格式的全屏角色

通过导入器生成的 Codex Pet 与小映共用角色大小、活动方式、移动速度和活动范围设置，可拖拽、站在页面元素上、散步和探头。行走分别使用原始向左、向右的动画行；助手思考、说话与完成状态使用素材包动作映射。

已有导入包按 Codex 网格及 idle、wave、happy-jump 的帧布局识别，保留形象 ID、原图与自定义动作。旧精简包缺少的行走等动作只在显示时补齐，无需删除或重新导入；普通素材包继续作为入口外观。

### 动画预览、映射与重命名

详情页保留完整原生动画预览：Codex Pet 的九组原生动画直接试播，不受映射覆盖影响；v2 另有 16 向视线预览。已有自定义动画保留，相同帧序列的适配别名不会重复算作新动画。小映提供完整姿态预览，入口形象提供 MP 动作与入口状态预览，全屏形象可模拟会话事件。

导入的 Codex Pet 可在详情页「动作映射」中为日常、会话、移动交互分别选择动画，例如思考、执行工具、完成、拖起和左右行走。映射以 Pet ID 独立保存，原始 `frames`、`actions` 和图片不变；留空或清除单项使用原有映射，也可恢复全部默认。缺少专用动画时提示使用待机。草稿只影响预览；「保存调整」保存活动参数、已修改 Pet 的映射与显示校准，「撤销」恢复已保存值。活动参数仍由全屏角色共用。

管理页的已导入 Codex Pet 卡片提供重命名，名称去除首尾空格后须为 1～40 个字符。仅显示名称变化，Pet ID、当前选择、动画、映射与用户位置保持不变。保存后更新管理卡片；详情页和宿主形象目录重新读取时显示新名称。内置形象不可重命名。

名称和映射保存均检查调用方读取的旧值；其他页面已修改时拒绝覆盖。映射草稿遇到外部更新时显示冲突提示，点击「撤销」载入最新值后重新调整，切换 Pet 或刷新不会绕过旧值检查。写入仅允许管理员。保存映射后通知当前页面对应实例与 Pet 重新读取，其他页面重新加载后取得新值。

| API | 用途 |
| --- | --- |
| `POST /api/v1/plugin/AgentPets/packs/rename` | `id`、`name`、`expected_name`；重命名并回读 |
| `POST /api/v1/plugin/AgentPets/packs/mappings` | `id`、`mappings`、`expected_mappings`；保存覆盖或用空对象恢复默认 |

### 素材显示校准

已导入素材在详情预览中可调整统一显示区域、脚底基线和水平／垂直偏移，并切换原始显示对照、显示参考框与底线。全部动画共用同一个框，不逐帧缩放；框外内容在显示时裁切，原始图片、帧序列与动作均保留。舞台边界和拖拽尺寸随有效显示区域更新。

「识别建议」读取已上传图片的透明边界，合并全部已定义帧及 Codex 显示补齐帧，按 idle 帧给出脚底基线；只生成草稿。远程 URL 素材可手动校准，自动识别需先上传图片。「恢复默认」也只改草稿，点击底部「保存调整」才持久化。其他页面已修改校准时拒绝覆盖，撤销后重新读取再调整。

### 完整素材包导出与导入

素材管理的已导入素材卡片提供「导出素材包」，生成 `<id>.agentpets.zip`，包含名称、说明、原始帧与动作、随机动作、自定义映射、显示校准、原始精灵图及现有预览图／头像。远程图片必须完整读取成功才会生成文件；跨域或网络失败会提示导出失败。

在「导入 Pet」区域切换到「AgentPets 素材包」，选择导出的 ZIP，先核对名称、图片与网格。相同 ID 默认「导入副本」，生成独立 ID 并保留原素材；明确选择「更新同 ID 素材」后展示覆盖范围与前后数量，核对后点击「确认覆盖此素材」。覆盖保留 ID、当前形象选择与个人位置，不允许普通入口形象与全屏角色相互覆盖。读取后素材被其他页面修改时，旧修订号会阻止覆盖。

覆盖前把上一份记录保存在插件数据键 `pack_backup_<id>`，并保留已上传的原图文件（远程来源仅保留原 URL）；恢复副本保存失败或无法回读时不覆盖。每个 ID 保留最近一次覆盖前的记录，旧图不自动清理；这份恢复记录用于故障排查，目前没有一键恢复界面，日常备份请保留导出的 ZIP。写入后状态不明会保留可恢复文件并提示核对，不把异常报告为成功。

ZIP 使用 `agentpets.json`（格式 `agentpets`、版本 `1`）和 `sheet.img`，可含 `preview.img`、`avatar.img`；图片保留原始字节并按内容识别格式。ZIP 上限 8MB，清单 64KB，精灵图 4MB，预览图和头像各 128 KiB，图片边长不超过 4096 像素。此格式使用「AgentPets 素材包」选项；Codex 的 `pet.json` ZIP 使用同一导入器中的「Codex Pet」选项。素材操作立即保存，不依赖详情页的「保存调整」。

### 入口外观

普通素材包只替换右下角助手入口的画面。拖拽、贴边、点击打开面板和气泡仍由主程序负责，行为和内置机器人一致。

- 内置戴红色贝雷帽的橘猫「放映猫」
- 每个素材包是一张精灵图加一份动作映射 JSON，按主程序传来的动作名和状态播放帧序列，没有对应映射时依次回落到状态、思考中和 idle
- 主程序暂停动画时只显示当前动作的第一帧
- 用户素材包在读取完成前不显示画面，读取失败时显示放映猫
- 管理员可在配置页添加素材包，上传的精灵图保存在插件数据目录，不写进插件代码目录
- 配置页可导入 Codex Pet ZIP 包或直接上传原生精灵图；v2 的 16 向帧可用于 scan 动作

## 一个插件注册多个形象

主程序通过插件的 `get_agent_pets()` 收集形象，返回列表里的每一项都是一个可选形象。`key` 在插件内唯一，用户的选择记作 `<插件 ID>:<key>`。本插件返回下面这些形象。

| key | mode | component | 说明 |
| --- | --- | --- | --- |
| `ying` | `stage` | `AgentPet` | 小映，插件拥有整个视口图层 |
| `projector-cat` | `renderer` | `AgentPetSprite` | 内置素材包 |
| Codex Pet 素材包 ID | `stage` | `AgentPetCodex` | 复用小映舞台与设置 |
| 普通素材包 ID | `renderer` | `AgentPetSprite` | 用户添加的每个普通素材包各一项 |

同一个联邦组件可以服务多个形象。Codex Pet 声明 `AgentPetCodex`，普通素材包声明 `AgentPetSprite`，组件从宿主传入的 `pet.key` 得知要画哪个素材包。形象列表随插件数据变化，添加或删除素材包后主程序重新读取声明即可看到。`preview` 和 `avatar` 支持相对联邦产物目录（`remoteEntry.js` 所在目录）的路径，或 `http(s)`、`data:` URL。内置形象使用缓存的轻量 `data:` 图片，供宿主选择卡片和消息头像直接显示；动画仍从联邦产物加载。

## 配置说明

| 配置项 | 标识 | 类型 | 默认值 | 说明 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 启用插件 | `enabled` | bool | `false` | 启用后形象出现在助手形象列表中 |  |
| 角色大小 | `scale` | number | `1` | 全屏角色的显示倍率，1 倍约 120 像素高 | 范围 0.6 到 1.6，窄屏再乘 0.8 |
| 活动方式 | `movement` | string | `auto` | `auto` 自主活动、`fixed` 固定位置 | 所有用户与全屏角色共用 |
| 移动速度 | `speed` | number | `1` | 全屏角色散步的速度倍率 | 范围 0.5 到 2 |
| 活动范围 | `roam` | string | `surfaces` | `surfaces` 站在页面元素上、`floor` 只在底边、`free` 自由活动 |  |

配置页保存开关前读取最新完整配置，保留详情页已保存的活动参数；读取失败或开关已在其他页面更改时停止提交。

配置页采用分组导航，提供运行总览、基础设置和素材管理；标题层级、分组排版与未保存提示参考订阅助手（增强版）。详情页集中选择 Pet、调整大小/活动方式/速度/活动范围，并在独立区域实时预览。预览复用正式形象的动作与移动逻辑，拖拽、落到平台、暂停和切换动作都不会修改正在使用的形象或保存位置。

活动参数仍由小映与全部 Codex Pet 共用，对所有用户生效；本轮不提供个人或手机／电脑独立偏好。「保存调整」只持久化这些参数并通知当前页面的运行形象；「撤销」恢复已保存值。

预览满意后点击「保存调整」，再到 MP 的「设定 → 系统 → 智能助手配置 → 助手形象」选择 Pet。详情页不再提供「立即生效」按钮；保存活动参数不会更改系统默认形象、个人选择或刷新页面。系统默认暂不可读时仍可预览和保存活动调整。

普通入口形象可预览动作，并在 MP 设置中选择使用；位置与移动由宿主管理，不显示全屏角色的活动参数。

素材包不属于插件配置。在配置页「素材管理」中点击「添加 Pet」并校验通过后立即保存，删除也立即生效，无需再点保存。

## 素材包格式

一个素材包由一张精灵图和一份 JSON 组成。精灵图按网格等分，所有格子同尺寸，建议透明背景、角色脚底在同一基线上。

```json
{
  "id": "my-pet",
  "name": "我的形象",
  "description": "一句话介绍",
  "sheet": "https://example.com/my-pet.png",
  "grid": { "cols": 4, "rows": 2 },
  "frames": { "idle": 0, "blink": 1, "talk": 2, "think": 3, "jump": 4, "wave": 5, "sleep": 6, "sad": 7 },
  "actions": {
    "idle": { "frames": ["idle", "idle", "idle", "blink"], "frame_ms": 700, "loop": true },
    "thinking": { "frames": ["think"], "loop": true },
    "speaking": ["talk", "idle"],
    "success": { "frames": ["jump", "wave", "idle"], "frame_ms": 260 },
    "error": ["sad"],
    "wave": { "frames": ["wave", "idle", "wave"], "frame_ms": 240 },
    "sleep": ["sleep"]
  },
  "random_actions": ["wave", "sleep"]
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 否 | 素材包 ID，也是形象 key，只能用小写字母、数字、`-`、`_`，1 到 32 个字符，不填时按名称生成。`projector-cat` 和 `ying` 留给内置形象 |
| `name` | 是 | 展示名，不超过 40 个字符 |
| `description` | 否 | 一句话介绍，不超过 120 个字符 |
| `sheet` | 视添加方式 | 选择「使用 JSON 中的图片 URL」时必须是 `http(s)` 图片地址，上传精灵图时忽略 |
| `grid` | 是 | `cols`、`rows`，各 1 到 16，精灵图宽高必须能被行列数整除 |
| `frames` | 是 | 帧名到格子索引，索引从左上角 0 开始逐行编号，必须包含 `idle` |
| `actions` | 否 | 主程序动作名或状态名到帧序列，详见下文 |
| `random_actions` | 否 | 主程序空闲时随机播放的动作，只能取下文的主程序动作名，不填则从全部动作中挑 |
| `action_mappings` | 否 | MP 事件到素材动作的自定义映射，导出时保留 |
| `calibration` | 否 | `left/top/right/bottom/baseline` 为 0～1，偏移 `offset_x/offset_y` 为 -0.25～0.25；区域宽高至少 0.1，基线在区域内 |
| `preview` | 否 | 自定义预览图，`http(s)` 地址或 `data:image/...`，上传方式不填时自动裁出 idle 帧 |
| `avatar` | 否 | Agent 面板用的方形头像，`http(s)` 地址或 `data:image/...`。上传方式不填时从 idle 帧角色顶部裁出，URL 方式不填则不提供头像 |

`actions` 的每一项写成对象 `{ "frames": [...], "frame_ms": 160, "loop": false }`，也可以直接写帧名列表，此时每帧 160 毫秒、不循环。`frame_ms` 范围 40 到 5000，不循环的动作播完停在最后一帧。

`actions` 的键可以是主程序动作名，也可以是状态名。

- 主程序动作名有 `wave`、`sit`、`eye-roll`、`faint`、`disassemble`、`happy-jump`、`sleep`、`stretch`、`peek`、`scan`、`charge`、`spin-cheer`、`shy`、`confused`、`nod`、`wake`
- 状态名有 `idle`、`thinking`、`speaking`、`notify`、`success`、`warning`、`error`、`dragging`、`docked`、`sleeping`、`reaction`

播放时先找当前动作名，找不到再找当前状态，助手正在思考时再试 `thinking`，最后用 `idle`。只给 `idle` 也能用，所有动作都会显示 idle。

精灵图支持 PNG、WebP、GIF 和 JPEG，不超过 4MB、边长不超过 4096 像素。Codex Pet ZIP 不超过 8MB，包内 `pet.json` 不超过 64KB。一个实例最多保存 20 个素材包。

## 使用步骤

1. 在插件市场安装并启用「助手形象」
2. 打开个人设置中的「助手形象」，选择「小映」或「放映猫」，管理员也可以在系统设置中设为默认助手形象
3. 打开插件详情页，选择 Pet 并调整大小、活动方式、速度和活动范围，在右侧实时预览；满意后点击「保存调整」
4. 需要更多 Pet 时，在配置页「素材管理」上传 `.zip` 或原生 PNG/WebP，点击「读取 Codex Pet」后「添加 Pet」；自定义素材仍可填写 JSON 并上传图片或使用图片 URL

Codex Pet 导入支持 v1 的 1536×1872（8×9）和 v2 的 1536×2288（8×11）精灵图。ZIP 包从唯一的 `pet.json` 读取 `spritesheetPath`、ID、名称和描述；直接上传图片时按文件名生成名称和 ID。导入器把前九行动画映射到 Agent 状态与动作；v2 最后两行的 16 个视线方向保留在素材包中，并映射到 scan 动作。生成后仍需点击「添加 Pet」保存；更换输入文件后须重新读取，避免新图片沿用旧名称和动作信息。新包带有 `codex_version`（`v1` 或 `v2`）以保留布局类型，选择该形象后使用全屏舞台。

插件详情页提供独立的实时预览，可拖动形象、切换招手/思考/说话等动作或暂停动画，调整不会影响正式使用的形象；退出时释放预览实例、监听器和计时器。

## 注意事项 / 已知风险

- 删除素材包或停用插件后，选择对应形象的用户会自动回到内置机器人
- 素材包使用图片 URL 时，图片由每个用户的浏览器直接加载，地址失效或跨域受限时会显示空白，需要稳定显示时请上传精灵图
- 全屏角色站在页面元素上时只认常见的卡片、面板和对话框容器，自定义布局里的普通区块不会成为落脚点
- Codex 是 OpenAI 的商标，本插件只兼容其 Pet 素材格式，与 OpenAI 无关联，也不附带任何 Codex Pet 素材；导入素材的版权由导入者负责

## 故障排查

- 主日志在 `MoviePilot/config/logs/moviepilot.log`
- 插件日志在 `MoviePilot/config/logs/plugins/`，过滤「助手形象」
- 常见问题
  - 形象列表里没有本插件的形象 → 确认插件已启用，主程序前端和后端都已升级到支持助手形象的版本
  - 选择后仍显示机器人 → 浏览器控制台中搜索 `AgentPet`，主程序会在联邦组件加载失败或超时时回退并给出一条警告
  - 「添加 Pet」提示帧或动作错误 → 按提示检查 `frames` 索引是否超出 `cols × rows`，动作里的帧名是否都在 `frames` 中
  - 选择素材包后显示的是放映猫 → 素材包读取失败时组件会退回内置素材包，浏览器控制台里会有 `[AgentPets]` 警告
