# 助手形象

为 Agent 助手提供可替换的形象，包括全屏活动的看板娘小映，以及用精灵图素材包定制的入口外观。

> 需要支持助手形象扩展的 MoviePilot 主程序，前端和后端都需要升级到包含该功能的版本。更早的主程序可以安装本插件，但不会出现这些形象，配置页顶部会提示升级。
>
> 适用于已启用 MoviePilot Agent 助手、想把右下角的机器人换成别的形象的场景。

## 版本更新日志

- v0.1.0

  - 小映的角色大小、移动速度和活动范围可调，调整时页面上的小映实时变化
  - 新增精灵图素材包形式的入口外观，内置放映猫，可在配置页上传精灵图或填写图片 URL 添加素材包

## 功能概览

启用插件后，个人设置的「助手形象」里会出现多个形象，每个用户自行选择，管理员也可以在系统设置中设为默认。每个形象都带一张方形头像，选中后 Agent 面板里的头像和名称也会跟着换。

插件只替换助手的外观和互动，不能代替用户发送消息，也不会接管助手面板、会话和模型。

### 全屏角色

小映是原创 Q 版看板娘，在整个页面上活动。

- 点击或用键盘 Enter / Space 打开助手面板
- 按住拖动会把她拎起来，松手后按重力落下，小小回弹后坐下再站起
- 空闲时偶尔散步、眨眼，走路是左右脚交替的四帧循环，步伐按走过的距离推进，调快速度也不会滑步
- 跟随助手状态换动作，思考、调用工具、等待确认、完成、出错、气泡和流式预览各有对应表情，长时间没有互动会打盹
- 不在按钮、链接、菜单项等可点击控件上方停留，挡住时自己走开，被放到控件上时约 1.5 秒后走开
- 手机等窄屏上在设置的大小基础上再缩小两成
- 记住每个用户的落脚点（活动范围和位置），在拖拽放下、改变活动范围和离开页面时保存，下次打开页面时按当前活动范围重新落位
- 系统开启「减少动态效果」时不播散步和下落，需要换位置时直接瞬移，页面切到后台时停止所有动画
- 帧图加载失败（例如服务重启中）时停在上一帧，不会出现破图框

活动范围有三种。

- **站在页面元素上**（默认）。落到正下方最近的卡片、面板或对话框上边，在上面走动，走到边缘会转身，偶尔跳下去。元素滚动、移动时她跟着走，元素缩小、关闭或滚出屏幕时她掉下去，没有可站的元素时落到屏幕底边
- **只在底边**。始终站在屏幕底边，偶尔走到一侧只探出上半身
- **自由停放**。没有重力，放在哪里停在哪里，空闲时在屏幕内慢慢游走

可站元素要求宽度至少 120 像素、上边缘在屏幕内、上方留得下她的身高，并且没有被遮罩或其他元素盖住。Agent 面板自身和不可见的元素不算。

### 入口外观

素材包只替换右下角助手入口的画面。拖拽、贴边、点击打开面板和气泡仍由主程序负责，行为和内置机器人一致。

- 内置戴红色贝雷帽的橘猫「放映猫」
- 每个素材包是一张精灵图加一份动作映射 JSON，按主程序传来的动作名和状态播放帧序列，没有对应映射时依次回落到状态、思考中和 idle
- 主程序暂停动画时只显示当前动作的第一帧
- 用户素材包在读取完成前不显示画面，读取失败时显示放映猫
- 管理员可在配置页添加素材包，上传的精灵图保存在插件数据目录，不写进插件代码目录

## 一个插件注册多个形象

主程序通过插件的 `get_agent_pets()` 收集形象，返回列表里的每一项都是一个可选形象。`key` 在插件内唯一，用户的选择记作 `<插件 ID>:<key>`。本插件返回下面这些形象。

| key | mode | component | 说明 |
| --- | --- | --- | --- |
| `ying` | `stage` | `AgentPet` | 小映，插件拥有整个视口图层 |
| `projector-cat` | `renderer` | `AgentPetSprite` | 内置素材包 |
| 素材包 ID | `renderer` | `AgentPetSprite` | 用户添加的每个素材包各一项 |

同一个联邦组件可以服务多个形象。所有素材包形象都声明 `AgentPetSprite`，组件从宿主传入的 `pet.key` 得知要画哪个素材包。形象列表随插件数据变化，添加或删除素材包后主程序重新读取声明即可看到。`preview` 和 `avatar` 写相对联邦产物目录（`remoteEntry.js` 所在目录）的路径，或 `http(s)`、`data:` URL。

## 命令 / API

| 类型 | 标识 | 说明 |
| --- | --- | --- |
| API | `GET /api/v1/plugin/AgentPets/settings` | 读取小映的已保存设置，登录用户可用 |
| API | `GET /api/v1/plugin/AgentPets/packs` | 素材包列表，登录用户可用 |
| API | `GET /api/v1/plugin/AgentPets/pack?key=<id>` | 读取一个素材包及精灵图，登录用户可用 |
| API | `POST /api/v1/plugin/AgentPets/packs` | 添加素材包，仅管理员 |
| API | `POST /api/v1/plugin/AgentPets/packs/delete` | 删除素材包，仅管理员 |

## 配置说明

| 配置项 | 标识 | 类型 | 默认值 | 说明 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 启用插件 | `enabled` | bool | `false` | 启用后形象出现在助手形象列表中 |  |
| 角色大小 | `scale` | number | `1` | 小映的显示倍率，1 倍约 120 像素高 | 范围 0.6 到 1.6，窄屏再乘 0.8 |
| 移动速度 | `speed` | number | `1` | 小映散步的速度倍率 | 范围 0.5 到 2 |
| 活动范围 | `roam` | string | `surfaces` | `surfaces` 站在页面元素上、`floor` 只在底边、`free` 自由停放 |  |

调整小映的设置时，页面上正在运行的小映会立即变化，不保存就关闭配置页会恢复原来的值。设置对所有用户生效。

素材包不属于插件配置。在配置页「添加素材包」里校验通过后立即保存，删除也立即生效，无需再点保存。

## 素材包格式

一个素材包由一张精灵图和一份 JSON 组成。精灵图按网格等分，所有格子同尺寸，建议透明背景、角色脚底在同一基线上。

```json
{
  "id": "my-pet",
  "name": "我的形象",
  "description": "一句话介绍",
  "sheet": "https://example.com/my-pet.png",
  "grid": { "cols": 4, "rows": 2 },
  "frames": { "idle": 0, "blink": 1, "talk": 2, "think": 3, "jump": 4, "wave": 5, "sleep": 6, "sad": 7 },
  "actions": {
    "idle": { "frames": ["idle", "idle", "idle", "blink"], "frame_ms": 700, "loop": true },
    "thinking": { "frames": ["think"], "loop": true },
    "speaking": ["talk", "idle"],
    "success": { "frames": ["jump", "wave", "idle"], "frame_ms": 260 },
    "error": ["sad"],
    "wave": { "frames": ["wave", "idle", "wave"], "frame_ms": 240 },
    "sleep": ["sleep"]
  },
  "random_actions": ["wave", "sleep"]
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 否 | 素材包 ID，也是形象 key，只能用小写字母、数字、`-`、`_`，1 到 32 个字符，不填时按名称生成。`projector-cat` 和 `ying` 留给内置形象 |
| `name` | 是 | 展示名，不超过 40 个字符 |
| `description` | 否 | 一句话介绍，不超过 120 个字符 |
| `sheet` | 视添加方式 | 选择「使用 JSON 中的图片 URL」时必须是 `http(s)` 图片地址，上传精灵图时忽略 |
| `grid` | 是 | `cols`、`rows`，各 1 到 16，精灵图宽高必须能被行列数整除 |
| `frames` | 是 | 帧名到格子索引，索引从左上角 0 开始逐行编号，必须包含 `idle` |
| `actions` | 否 | 主程序动作名或状态名到帧序列，详见下文 |
| `random_actions` | 否 | 主程序空闲时随机播放的动作，只能取下文的主程序动作名，不填则从全部动作中挑 |
| `preview` | 否 | 自定义预览图，`http(s)` 地址或 `data:image/...`，上传方式不填时自动裁出 idle 帧 |
| `avatar` | 否 | Agent 面板用的方形头像，`http(s)` 地址或 `data:image/...`。上传方式不填时从 idle 帧角色顶部裁出，URL 方式不填则不提供头像 |

`actions` 的每一项写成对象 `{ "frames": [...], "frame_ms": 160, "loop": false }`，也可以直接写帧名列表，此时每帧 160 毫秒、不循环。`frame_ms` 范围 40 到 5000，不循环的动作播完停在最后一帧。

`actions` 的键可以是主程序动作名，也可以是状态名。

- 主程序动作名有 `wave`、`sit`、`eye-roll`、`faint`、`disassemble`、`happy-jump`、`sleep`、`stretch`、`peek`、`scan`、`charge`、`spin-cheer`、`shy`、`confused`、`nod`、`wake`
- 状态名有 `idle`、`thinking`、`speaking`、`notify`、`success`、`warning`、`error`、`dragging`、`docked`、`sleeping`、`reaction`

播放时先找当前动作名，找不到再找当前状态，助手正在思考时再试 `thinking`，最后用 `idle`。只给 `idle` 也能用，所有动作都会显示 idle。

精灵图支持 PNG、WebP、GIF 和 JPEG，不超过 4MB、边长不超过 4096 像素。一个实例最多保存 20 个素材包。

## 使用步骤

1. 在插件市场安装并启用「助手形象」
2. 打开个人设置中的「助手形象」，选择「小映」或「放映猫」，管理员也可以在系统设置中设为默认助手形象
3. 选了小映时，在插件配置页调整角色大小、移动速度和活动范围，确认效果后保存
4. 需要更多入口外观时，在配置页粘贴素材包 JSON，上传精灵图或改用 JSON 中的图片 URL，点击「校验并添加」

插件详情页提供开发预览，分小映和素材包两块，可以放出一只独立的预览小映、逐个触发助手事件，或按入口大小检查素材包的帧映射。

## 注意事项 / 已知风险

- 删除素材包或停用插件后，选择对应形象的用户会自动回到内置机器人
- 素材包使用图片 URL 时，图片由每个用户的浏览器直接加载，地址失效或跨域受限时会显示空白，需要稳定显示时请上传精灵图
- 小映站在页面元素上时只认常见的卡片、面板和对话框容器，自定义布局里的普通区块不会成为落脚点

## 故障排查

- 主日志在 `MoviePilot/config/logs/moviepilot.log`
- 插件日志在 `MoviePilot/config/logs/plugins/`，过滤「助手形象」
- 常见问题
  - 形象列表里没有本插件的形象 → 确认插件已启用，主程序前端和后端都已升级到支持助手形象的版本
  - 选择后仍显示机器人 → 浏览器控制台中搜索 `AgentPet`，主程序会在联邦组件加载失败或超时时回退并给出一条警告
  - 「校验并添加」提示帧或动作错误 → 按提示检查 `frames` 索引是否超出 `cols × rows`，动作里的帧名是否都在 `frames` 中
  - 选择素材包后显示的是放映猫 → 素材包读取失败时组件会退回内置素材包，浏览器控制台里会有 `[AgentPets]` 警告
