# 小映桌宠

原创 Q 版看板娘助手形象，可拖拽、下落、沿屏幕底边散步，并随 Agent 状态播放动作。

> 兼容性：MoviePilot v3.x，需要主程序支持 Agent 助手形象扩展（`get_agent_pets` 与 `moviepilot:agent`）；不支持的主程序会继续显示内置机器人
> 适用场景：已启用 MoviePilot Agent 助手，想把右下角的机器人换成一个可以互动的桌宠

## 版本更新日志

- v0.1.0
  - 新增 stage 模式助手形象小映：点击打开助手面板，可拖拽、下落、沿屏幕底边散步和探头，按 Agent 状态播放动作
  - 支持调整角色大小与移动速度，拖动滑块时页面上的小映实时变化

## 功能概览

- 小映住在屏幕底边，点击或用键盘 Enter / Space 打开原生 Agent 面板，面板、会话和模型仍由主程序负责
- 按住拖动会把她拎起来，松手后按重力落回地面，小小回弹后坐下再站起；地面会避开安全区和手机软键盘
- 空闲时偶尔沿底边左右散步、眨眼，有时走到一侧只探出上半身；助手面板挡住底边时她会绕开
- 跟随助手状态换动作：思考、调用工具、等待确认、完成、出错、气泡和流式预览各有对应表情，长时间没有互动会打盹
- 记住每个用户最后的落脚位置，下次打开页面时回到原处
- 系统开启「减少动态效果」或页面切到后台时停止所有动画，拖拽松手后直接落到地面

小映只替换助手入口的外观和互动，不能代替用户发送消息，也不会接管助手面板。

## 命令 / API

| 类型 | 标识 | 说明 |
| --- | --- | --- |
| API | `GET /api/v1/plugin/AgentPetYing/settings` | 读取已保存的角色大小和移动速度，登录用户可用 |

## 配置说明

| 配置项 | 标识 | 类型 | 默认值 | 说明 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 启用插件 | `enabled` | bool | `false` | 启用后小映出现在助手形象列表中 |  |
| 角色大小 | `scale` | number | `1` | 角色显示倍率，1 倍约 120 像素高 | 范围 0.6 到 1.6 |
| 移动速度 | `speed` | number | `1` | 散步速度和步伐节奏倍率 | 范围 0.5 到 2 |

拖动「角色大小」和「移动速度」滑块时，页面上正在运行的小映会立即变化；不保存就关闭配置页会恢复原来的值。设置对所有用户生效。

## 使用步骤

1. 在插件市场安装并启用「小映桌宠」
2. 打开个人设置中的「助手形象」，选择「小映」；管理员也可以在系统设置中把她设为默认助手形象
3. 回到任意页面，点击屏幕底部的小映打开助手面板，或拖着她换个位置
4. 需要调整大小或速度时，在插件配置页拖动滑块确认效果后保存

插件详情页提供开发预览，可以放出一只独立的预览小映并逐个触发助手事件，查看各个动作。

## 注意事项 / 已知风险

- 停用插件或卸载后，已选择小映的用户会自动回到内置机器人，不需要逐个修改
- 落脚位置按用户保存在主程序的用户配置里，把她拖到新位置后自动更新

## 故障排查

- 主日志：`MoviePilot/config/logs/moviepilot.log`
- 插件日志：`MoviePilot/config/logs/plugins/`，过滤「小映桌宠」
- 常见问题：
  - 形象列表里没有小映 → 确认插件已启用，主程序版本支持助手形象扩展
  - 选择后仍显示机器人 → 浏览器控制台中搜索 `AgentPet`，主程序会在联邦组件加载失败或超时时回退并给出一条警告
  - 滑块拖动时小映不变化 → 主程序没有提供 `moviepilot:agent` 时只能保存后刷新页面生效
