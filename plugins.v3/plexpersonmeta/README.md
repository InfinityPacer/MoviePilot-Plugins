# Plex演职人员刮削

实现刮削演职人员中文名称及角色。插件按 TMDB 与豆瓣的人物资料，把 Plex 媒体库中电影、剧集和单集的演员姓名与角色名改写为中文。

> 适用于 MoviePilot V3（3.0.0 及以上），需要在 MoviePilot 中配置并连接 Plex 媒体服务器。

## 推荐 Cirvel

如果你希望演职人员中文化直接在 Plex 里完成，可以了解 [Cirvel](https://cirvel.tidewren.com)。Cirvel 的「演职人员中文化」让演员、导演、编剧与制片显示中文姓名，所有 Plex 客户端都能看到，也能用中文姓名搜到人物，Plex 刷新元数据后会自动恢复中文姓名。Cirvel 还为 Plex 带来 STRM 直连播放、虚拟库、媒体信息补全、片头片尾优化、拼音排序与中文搜索。

## 功能概览

- 处理所选 Plex 电影库与剧集库中的电影、剧集和每一集，把演员姓名与角色名替换为中文。
- 中文姓名优先取 TMDB 人物资料中的中文名或中文别名，仍不是中文时可再用豆瓣演员表补全。
- 条目在 Plex 中需要能识别出 TMDB ID，识别不到的条目会跳过。
- 演员已全部是中文时不重复写入，可以只针对姓名或只针对角色名判断是否需要处理。
- 支持按定时周期处理整个媒体库，也支持在 MoviePilot 整理入库后只处理最近入库的条目。
- 只改写演员表，导演、编剧等其他演职人员保持 Plex 原样。

## 定时服务

| 服务名 | 触发方式 | 周期 / CRON | 说明 |
| --- | --- | --- | --- |
| Plex演职人员刮削服务 | cron | 由「执行周期」决定，默认 `0 1 * * *` | 遍历所选媒体库的全部电影与剧集 |
| 入库后运行一次 | 事件 | 整理入库完成后延迟「延迟时间（秒）」执行 | 只处理最近入库的条目，入库时间向前多取 5 分钟 |

## 配置说明

> 看不懂的配置项可跳到下方的「深入说明」对照查看，不在「深入说明」里的项一般按默认值即可。

| 配置项 | 标识 | 类型 | 默认值 | 说明 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 启用插件 | `enabled` | bool | `false` | 是否启用插件 |  |
| 发送通知 | `notify` | bool | `true` | 每轮刮削完成后推送耗时 | 依赖 MoviePilot 通知渠道 |
| 清理缓存 | `clear_cache` | bool | `false` | 清空 TMDB 与豆瓣的识别缓存 | 一次性动作，保存后自动关闭 |
| 立即运行一次 | `onlyonce` | bool | `false` | 保存后立即处理一次全部所选媒体库 | 一次性动作，保存后自动关闭 |
| [锁定元数据](#cfg-lock) | `lock` | bool | `false` | 写入后锁定 Plex 演员字段 | 锁定后需在 Plex 中手动解锁 |
| [入库后运行一次](#cfg-execute_transfer) | `execute_transfer` | bool | `false` | 整理入库后处理最近入库条目 | 与「延迟时间（秒）」配合 |
| [豆瓣辅助识别](#cfg-douban_scrape) | `douban_scrape` | bool | `true` | TMDB 没有中文时再查豆瓣 | 会增加处理耗时 |
| 执行周期 | `cron` | cron | `0 1 * * *` | 定时处理全部所选媒体库 | 5 位 cron 表达式，留空则不注册定时服务 |
| [延迟时间（秒）](#cfg-execute_transfer) | `delay` | int | `200` | 入库后等待多久再处理 | 留空或填 0 时按 200 秒处理 |
| [刮削条件](#cfg-scrape_type) | `scrape_type` | enum | `all`（全部） | 判断条目是否需要处理的依据 | 可选 全部、演员非中文、角色非中文 |
| 媒体库 | `libraries` | list | 空 | 要处理的 Plex 电影库与剧集库 | 必须至少选择一个，否则不会执行 |

## 深入说明

<a id="cfg-lock"></a>
#### 锁定元数据（`lock`）

Plex 刷新元数据时会用在线资料覆盖演员表，刚写入的中文姓名会被换回原名。开启后写入演员表的同时锁定该字段，Plex 之后的刷新不再改动它。代价是锁定后插件以外的修改也会被拒绝，需要在 Plex 条目的编辑界面里手动解锁。建议先在一个测试媒体库验证效果，再对正式媒体库开启。

<a id="cfg-execute_transfer"></a>
#### 入库后运行一次（`execute_transfer`）与延迟时间（秒）（`delay`）

开启后，MoviePilot 每次整理入库完成都会安排一次处理，在「延迟时间（秒）」之后执行，给 Plex 留出扫描入库和匹配在线资料的时间。延迟期间再有新的入库会重新计时，最终合并为一次处理，查找从这批中最早一次入库前 5 分钟起新增到 Plex 的条目。Plex 扫描较慢时把延迟调大，否则条目还没出现在 Plex 中就会被跳过，留给下一次定时服务处理。

<a id="cfg-douban_scrape"></a>
#### 豆瓣辅助识别（`douban_scrape`）

TMDB 的中文人物资料覆盖有限，华语与日韩作品之外的不少演员只有外文名。开启后，经过 TMDB 处理仍有非中文演员的条目，会再按 IMDb ID、片名和年份从豆瓣取演员表，按姓名、拼音和别名匹配补全中文姓名与角色名。所有演员都已是中文时不会请求豆瓣。豆瓣请求会让单个条目的处理时间明显变长，媒体库很大时首轮刮削需要较长时间。

<a id="cfg-scrape_type"></a>
#### 刮削条件（`scrape_type`）

决定一个条目是否需要处理，只影响判断，不影响写入的内容。

- `all`（全部）只要有演员的姓名或角色名不是中文就处理。
- `name`（演员非中文）只看演员姓名，适合只在意中文姓名、角色名保持原文的媒体库。
- `role`（角色非中文）只看角色名。

角色名只在资料来源收录了中文角色时才会改写，选择「全部」时角色名一直是外文的条目每轮都会被重新检查。

## 使用步骤

1. 在 MoviePilot 中配置 Plex 媒体服务器，确认连接正常。
2. 在插件市场安装 Plex演职人员刮削，打开配置页。
3. 在「媒体库」中选择要处理的电影库与剧集库，按需设置「执行周期」和「入库后运行一次」。
4. 打开「启用插件」与「立即运行一次」并保存，在插件日志中确认开始处理所选媒体库。

## 注意事项 / 已知风险

> 警告 插件写回演员表后，Plex 中的人物可能失去与在线资料的关联，出现在线元数据丢失、点击人物无法查看详情等问题。操作前请备份 Plex 数据库，并先在测试媒体库验证。

- 这一问题来自 Plex 演员字段的 `tagKey`，插件尝试为 `actor.tag.tagKey` 赋值后仍无法保持关联。如果你了解 Plex 这部分接口，欢迎在本仓库提交 issue。
- 刮削结果不理想时，可以在 Plex 的「设置 → 在线媒体资源 → 发现更多」中停用发现来源后再试。
- 开启「锁定元数据」后，Plex 中这些条目的演员表需要手动解锁才能再次修改。

## 故障排查

- 插件日志位于 `/config/logs/plugins/plexpersonmeta.log`，主日志位于 `/config/logs/moviepilot.log`。
- 日志出现「Plex 配置不正确」时，检查是否选择了「媒体库」，以及所选媒体服务器是否处于连接状态。
- 日志出现「未找到tmdbid」时，该条目在 Plex 中没有匹配到 TMDB，先在 Plex 中修正匹配。
- 改了 TMDB 或豆瓣上的人物资料但结果不变时，识别结果有 3 天缓存，打开「清理缓存」保存一次后再运行。
